SafeRide USB and Bluetooth connection help
==========================================

SafeRide itself is fully offline and includes its Python runtime, Arduino
compiler, upload tools, and AVR board definitions. No Arduino IDE is needed.

If a connected Arduino does not appear in SafeRide:

1. Use a USB data cable. Some charging cables do not carry data.
2. Reconnect the board, then press RESCAN in SafeRide.
3. Open Windows Device Manager and check "Ports (COM & LPT)" and
   "Other devices".
4. For an official Arduino Uno or Mega, allow Windows Update to install the
   signed device driver.
5. Many clone Uno and Nano boards use a CH340/CH341 USB chip. Install the
   signed CH340/CH341 driver supplied by the board seller or chip vendor, then
   reconnect the board and press RESCAN.

Do not download USB drivers from random driver-download websites.

Bluetooth / HC-05 mode:

1. SafeRide first uploads Bluetooth firmware through both USB cables.
2. After the upload completes, follow the on-screen wiring diagram and power
   both boards from the project battery or a regulated supply.
3. Use OPEN WINDOWS BLUETOOTH in SafeRide to pair both HC-05 modules. The
   normal PIN is 1234; some modules use 0000.
4. Return to SafeRide, press RESCAN PORTS, then AUTO IDENTIFY.
5. SafeRide recognizes the helmet and vehicle from their live packet formats,
   remembers the two Bluetooth COM ports, and opens the dashboard.

Windows owns Bluetooth pairing and its trusted-device record. SafeRide opens
the official Windows pairing screen rather than storing or bypassing the PIN.
